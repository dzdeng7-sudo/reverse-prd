# reverse-prd

读取现有系统的代码，按内置的《通用产品需求文档 PRD 标准模板》反向梳理产品需求文档（PRD）。适用于 ZCode 等支持 Agent Skills（`.agents/skills`）机制的 AI 编程工具。

## 解决什么问题

新产品/新成员要熟悉现有系统功能，靠人工截图找开发逐个确认效率太低。加载本技能后，AI 会：

1. 通读相关模块的代码（入口层 → 页面层 → 服务层 → 数据层 → 权限配置）
2. 严格按模板章节输出 PRD：功能结构 → 业务描述 → 业务流程 → 功能规则（含状态表、权限表）→ 功能详情 → 各子功能的输入输出描述与页面操作语
3. 只写代码中有依据的当前行为，不写未来方案、不推测未核实的规则；代码读不出的信息不编造，汇总在对话中供人工核实

## 安装

把整个 `reverse-prd` 文件夹复制到 AI 工具的技能目录（如 ZCode 的用户级技能目录 `~/.agents/skills/`），新会话生效。之后对 AI 说"梳理 XX 模块的 PRD"即可触发。

## 说明

- 本仓库是 PRD 产出类技能，与 `ai-doc-skills` 中的通用文档写作规范分开维护。
- `assets/` 目录内置《通用产品需求文档 PRD 标准模板》；模板更新后直接替换该文件并提交即可。
